### O que eu construo

**Engenharia de dados**

- **Extração paginada em larga escala:** ferramenta de extração de dados de plantas industriais, que roda como serviço contínuo, percorre as fontes de forma paginada, guarda estado/cache para retomar de onde parou e faz a ingestão no data lake/banco analítico. É a minha maior ferramenta de dados hoje.
- **Tráfego de dados online:** serviço que envia continuamente os indicadores de produção (OEE) das plantas para a nuvem, alimentando dashboards em tempo quase real.
- **Pipelines em arquitetura medalhão** (bronze/prata/ouro), com processamento em **Spark** e armazenamento em **Parquet/Delta**.
- **Dashboards em Power BI**, online e históricos, para acompanhar indicadores operacionais.
- **Integração com ERPs e APIs**, consolidando dados em SQL Server como base para relatórios e análises.

**RPA**

- **Fiscal e faturamento:** robôs que tratam documentos fiscais (XML), fazem conferências e cuidam das etapas repetitivas do faturamento, reduzindo erro manual num processo crítico.
- **Extração e raspagem web:** robôs que acessam portais e sistemas web, extraem e raspam dados (Selenium / Playwright) e consolidam tudo em planilhas e bancos para as áreas de negócio, como administração de vendas.
- **Mapeamento e documentação de processos** (fluxogramas e análise de sistemas) antes de automatizar.
- **Sustentação e evolução de robôs** em produção: monitoramento, correção e melhoria contínua.
